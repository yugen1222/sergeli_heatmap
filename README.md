# Sergeli Heatmap v2

Файлы:
- index.html
- style.css
- firebase.js
- app.js
- sw.js
- floor1.mp3
- floor2.mp3
- floor3.mp3

## Установка
1. Загрузите все файлы в корень GitHub-репозитория.
2. Добавьте свои MP3 с точными именами floor1.mp3, floor2.mp3, floor3.mp3.
3. В Render Publish Directory оставьте точку: .
4. После обновления откройте сайт и один раз нажмите «Включить голос».


## Если голос не слышно
1. После каждого нового открытия страницы нажмите «Включить голос».
2. Сначала должна полностью проиграться запись первого этажа — это проверка браузерного разрешения.
3. Проверьте прямые адреса:
   - /floor1.mp3
   - /floor2.mp3
   - /floor3.mp3
4. На телевизоре отключите беззвучный режим и разрешите сайту воспроизведение звука.
