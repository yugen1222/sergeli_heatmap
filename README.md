# Один файл сайта

1. Замените старый index.html этим файлом.
2. Оставьте рядом:
   - firebase-messaging-sw.js
   - floor1.mp3
   - floor2.mp3
   - floor3.mp3
3. style.css, app.js и firebase.js больше не нужны.
4. После загрузки сделайте Manual Deploy в Render или дождитесь автодеплоя.
5. Для голоса нажмите «Включить голос».
6. Для фоновых Push всё ещё нужен VAPID key в index.html и развернутая Cloud Function.
