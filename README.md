## Установка
1. Загрузите все файлы в корень GitHub-репозитория.
2. Добавьте свои MP3 с точными именами floor1.mp3, floor2.mp3, floor3.mp3.
3. В Render Publish Directory оставьте точку: .
4. После обновления откройте сайт и один раз нажмите «Включить голос».
